# Alright!

Site vitrine de Jonathan Collomb, operating partner des dirigeants de PME.

Les fichiers du site se trouvent dans `dist/` :
- `index.html` : page du site, styles et contenu.
- `favicon.svg` : icône du site.

## Publication sur Netlify

Importer ce dépôt GitHub, laisser la commande de build vide et définir le dossier de publication sur `dist`.

Le site est statique et ne nécessite aucune installation de dépendances.
